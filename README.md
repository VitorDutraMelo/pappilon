## 🛠️ Project structure

This repository contains the agency's website. The available project version uses a static HTML page and an image directory.

```text
pappilon/
├── index.html           # Main website
├── images/              # Photography and visual assets
├── favicon.ico          # Browser icon
├── CNAME                # Custom domain configuration
└── README.md            # Project documentation
```

### Run locally

Clone the repository and open `index.html` in your browser. For a local web server, you can run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

> The exact repository structure may evolve as the website grows. This README describes the static site files reviewed for this documentation.
